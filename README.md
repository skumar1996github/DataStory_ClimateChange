# Climate Change – Data Story Project

This repository contains a data-driven visual storytelling project on climate change, created as part of the course MDSSBO-203: Visual Communication and Data Storytelling (Fall 2025), instructed by Prof. Jan Lorenz.

The project explores the relationship between carbon dioxide (CO₂) emissions, global temperature change, economic development, and climate responsibility using publicly available datasets and visualizations. The goal is to communicate complex climate data in a clear, accessible, and visually compelling way.

## Project Objectives:

To analyze how global CO₂ emissions relate to global temperature change

To examine how economic growth influences emissions across countries

To highlight inequalities in climate responsibility using current, historical, and per-capita emissions

To apply principles of visual communication and data storytelling to climate data

## Data Sources:

The project uses the following publicly available datasets:

Our World in Data (OWID), CO₂ emissions data by country and globally

https://ourworldindata.org/co2-emissions

Hadley Centre, Global average temperature anomaly data (via OWID GitHub)

https://github.com/owid/owid-datasets/

World Bank, Country-level population data

https://data.worldbank.org
